# hanoi-3d-game
# 3D Tower of Hanoi Game
炫酷星空背景 **3D 汉诺塔** 网页小游戏，原生 HTML + CSS + JavaScript 开发，无任何第三方库，自带递归自动解题、暂停继续、步数统计、合法校验、通关动画全套功能。

## ✨ 项目特色
- 唯美星空动态背景 + 流星划过特效
- 深色宇宙科幻风格 UI，毛玻璃磨砂质感
- 纯原生 DOM 实现，**无 Canvas / SVG 游戏引擎**
- 完整汉诺塔规则校验，禁止大盘压小盘、只能移最顶部圆盘
- 递归算法生成最优解，一键自动演示完整解题过程
- 自动解题支持 **暂停 / 继续**
- 圆盘数量 2～10 自由调节
- 实时步数统计 + 理论最少步数计算
- 选中上浮、非法抖动、通关摇摆全套动画
- 通关弹窗提示，可重新开始对局

## 🎮 游玩方式
1. 拖动滑块 / 输入数字，选择圆盘数量（2～10）
2. 点击柱子上方圆盘进行选中，再点击目标柱子完成移动
3. 遵守规则：只能移动最顶端圆盘，大圆盘不能放在小圆盘上方
4. 点击 `重置游戏` 随时重新开局
5. 点击 `自动解题` 观看算法最优解演示，可中途暂停继续

## 🧰 技术实现
- HTML5：页面结构、布局搭建
- CSS3：3D 透视、渐变、阴影、毛玻璃、keyframes 动画
- JavaScript：
  - 面向对象开发，代码结构清晰
  - 二维数组存储三根柱子圆盘状态
  - 递归算法生成汉诺塔最优移动步骤
  - setTimeout 异步分步动画演示
  - 原生 Canvas 绘制星空+流星背景
  - 完善边界判断与用户操作防抖

## 📚 使用到的数组方法
- `Array.push()`：圆盘放入目标柱子
- `Array.pop()`：取出柱子最上方圆盘
- `Array.at(-1)`：获取柱子顶部圆盘
- `Array.forEach()`：遍历渲染柱子与圆盘元素
- 递归深度遍历：自动生成所有移动步骤
